# 晕动舒缓（MotionGuard）

**一款由 ChatGPT 辅助设计与开发的 Android 晕车舒缓功能。**

项目希望通过设备运动传感器识别乘车过程中的运动变化，并借鉴 Apple Vehicle Motion Cues、Google Motion Assist 等视觉提示思路，在屏幕上呈现动态提示，帮助用户缓解乘车时的晕动不适。

> 这里的“基于 ChatGPT”指项目方案设计、技术研究与代码开发过程中使用 ChatGPT 辅助；当前设计不代表应用运行时必须连接 ChatGPT，也不代表已经接入 OpenAI API。

## 项目目标

- 设计简单、清晰、可手动启停的晕车舒缓功能。
- 自动分析设备运动特征，在疑似乘车场景下显示动态视觉提示。
- 尽量减少误触发，并提供可调整的提示行为。
- 以实际设备测试为依据逐步验证效果，不夸大缓解能力。

## 首要目标设备与环境

- 设备：OPPO K13 Turbo（PLM110）
- 系统：Android 16
- 模块接口：LSPosed Modern API 102
- Root 环境：KernelSU

## 第一阶段开发目标

1. 建立独立 Android 控制界面，提供总开关、基础设置和运行状态。
2. 验证传感器数据采集、运动特征判断、滤波和误触发抑制。
3. 实现独立的动态视觉提示层。
4. 评估 LSPosed system 作用域是否确有必要，优先采用最小注入范围。
5. 做好权限说明、异常处理和功能关闭后的资源释放。

## 设计约束

- GitHub 仓库保持 **Private**，不公开项目源码。
- LSPosed Modern API 102 的目标作用域按设计限定为 `system`；完成兼容性验证前不扩大作用域。
- 日常启停优先通过运行时状态配置完成，避免要求用户反复重启设备。
- 首次启用所需的注入和重启要求必须如实说明。
- 传感器只能估计运动特征，无法百分之百区分车辆、步行和手持晃动；不能保证适用于所有车辆，也不能保证消除晕动症状。

## 开发状态

已提交第一版前台传感器原型：支持手动开始/停止、线性加速度优先、加速度计重力分离回退，以及应用内动态圆点提示。当前仅在主界面可见期间采集数据；尚未实现车辆分类、后台运行、系统级覆盖层或实际 system_server Hook。仍需 GitHub Actions 构建验证和 OPPO K13 Turbo 实机测试。
