# 晕动舒缓（MotionGuard）

一款帮助缓解乘车晕动不适的 Android 辅助工具。

## 项目目标

参考 Apple Vehicle Motion Cues 与 Google Motion Assist 的视觉提示思路，通过设备运动传感器识别疑似乘车运动，并显示可配置的动态视觉提示，帮助用户缓解晕动不适。

## 首要目标设备

- 设备：OPPO K13 Turbo（PLM110）
- 系统：Android 16
- 模块接口：LSPosed Modern API 102
- Root 环境：KernelSU

## 第一阶段目标

1. 建立独立的 Android 控制界面，提供总开关和基础设置。
2. 验证传感器数据采集、运动特征判断与误触发抑制。
3. 实现独立的动态视觉提示层。
4. 评估 LSPosed system 作用域的必要性；优先采用最小注入范围。
5. 提供清晰的权限说明、状态反馈和故障保护。

## 设计约束

- 仓库保持 Private，不公开项目源码。
- LSPosed Modern API 102 的目标作用域按设计限定为 `system`；在完成兼容性验证前，不扩大作用域。
- 日常启停应通过运行时状态配置完成，避免要求用户反复重启设备。
- 首次启用所需的注入和重启要求必须如实说明。
- 传感器只能估计运动特征，不能保证准确识别所有车辆场景，也不能保证消除晕动症状。

## 开发状态

项目初始化阶段。尚未提交可安装 APK；传感器策略、视觉样式、进程边界和权限方案需要在实现前验证。
