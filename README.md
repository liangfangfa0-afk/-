# 晕动舒缓（MotionGuard）

Android 运动状态提示应用。

## 当前功能
- 线性加速度优先；缺失时回退到加速度计并进行重力分离。
- 低通滤波与滚动 RMS 运动强度估计。
- 粗略区分相对静止、轻微运动、持续运动和明显颠簸。
- 前台服务在应用切到后台后继续采集，并通过常驻通知显示状态、提供停止操作。
- 应用内动态提示圆点和实时传感器数值。

## 限制
状态分类描述的是设备运动特征，不是车辆识别器。步行、手持晃动和桌面震动都可能产生相似数据。动态提示不会覆盖其他应用，也不是医疗治疗或缓解效果保证。Android/OEM 仍可能因电池策略终止后台服务。

## LSPosed
保留 Modern API 102 引导入口，目标 scope 仍限定为 `system`。本版本尚未实现 system_server Hook；启用与否不会改变应用的传感器采集和提示功能。

通过 GitHub Actions 构建 debug APK。实机验证、长时间后台稳定性测试和正式签名仍需完成。
